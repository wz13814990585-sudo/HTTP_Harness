## Implemented

- `DecisionRouter` is an optional bounded provider port. It accepts only
  `simple`/`plan_hint`, validates distribution and threshold, and falls back on
  timeout, provider failure, disabled mode, low confidence, or malformed output.
  Its output is a persisted strategy hint, never a permission decision.
  Runtime validation now rejects a wrong result-object type, boolean
  probabilities, and non-finite or boolean timeout/threshold configuration
  instead of allowing malformed optional-provider output to abort the Run.
- `TypeSafeDecisionProvider` calls the pinned HTTPS System One endpoint with a
  fixed Choice question and only the two strategy labels. The bearer credential
  stays server-side, redirects and proxy-environment inheritance are disabled,
  response bodies are not logged, and every provider failure falls back to
  `simple`. The development worker constructs it only when explicitly enabled.
- Router validation treats TypeSafe `confidence` as a statistic derived from the
  full probability distribution, rather than requiring it to equal the selected
  label probability. The selected label must still be a maximum-probability choice.
- `SkillLoader` loads only trusted allowlisted files within its root, with a size
  limit and SHA-256 revision. The first model context pins exact skill references
  in PostgreSQL; later content drift raises `migration_required`. Context records
  source references and labels the text as untrusted guidance.
- An opt-in P08 skills off/on evaluator now executes real PostgreSQL Runs under
  the same native read-only capability and budget. Only the on condition loads
  an allowlisted, SHA-pinned skill; both conditions still use the common
  ActionGateway. A local mocked-Responses test verifies the context toggle,
  source references and identical gateway path. It is ablation wiring, not
  measured skill benefit or live TypeSafe evidence.
- Internal-only `admit_child_run` commits the child Run, Event, Job, Budget,
  parent-child event and parent quota reservations in one transaction.
  It intersects requested scopes with caller/parent scopes, enforces finite
  model/tool/output budgets, requires cost and remaining wall-time bounds when
  the parent has them, and bounds depth and child count. Runner,
  ContextBuilder and ActionGateway use the child's effective delegated scopes.
- Parent cancellation marks live descendants `cancelling` in the same transaction.
  `finalize_run_cancellation` refuses to confirm stop while descendants or actions
  remain unresolved. CompletionGate also rejects completion with active children.
  The bounded development worker now claims `cancel_run` jobs with a fenced
  lease and current trusted actor, draining a child before its parent when no
  unresolved effects remain. It defers unknown effects for reconciliation; a
  late model response cannot admit a new Action after cancellation.

## Limits

- The live TypeSafe call proves request/response compatibility only. The confidence
  threshold is a routing rule, not an empirical calibration or safety probability.
  P08 must evaluate it as a separate ablation before claiming benefit.
- The new skills ablation has no real-model raw dataset yet; its checked-in
  echo guidance and local mock cannot establish a positive effect. Classifier
  and child-run benefit likewise remain unevaluated with a live model.
- Child quotas are conservatively reserved in the parent; unused allocations are
  not automatically reclaimed in this slice. This prevents overspend but can
  reduce available parent capacity after child termination.
- Child creation is trusted in-process only, not a model-visible endpoint. There
  is no general multi-agent orchestration bus. Root-run authorization still uses
  the transport's current trusted context; this is not production OIDC.
- The development worker automatically drains confirmable local cancellation
  jobs, but cannot prove a remote operation stopped or reconcile an unknown
  external effect. Those jobs remain deferred until adapter-specific or human
  evidence arrives; no production cancellation supervisor is claimed.
- Terminalizing a parent through other kernel paths is refused while a child is
  active, so failure/completion cannot silently orphan the child. Operators
  should request cancellation and reconcile descendants first.
