# P00 implementation report

Date: 2026-09-22 (Australia/Sydney)

Status: **complete**. This status covers only the P00 engineering and contract
baseline. It is not evidence that the durable kernel, model loop, sandbox, MCP
adapter, or any target `/v1` operation exists.

## Delivered

- Python 3.12 `src/` package with a FastAPI application factory and health probe.
- Reproducible `pyproject.toml` and `uv.lock`, including an optional MCP SDK extra.
- pytest, coverage, Ruff, strict mypy, and GitHub Actions quality gates.
- Executable JSON Schema example tests for AT-001.
- OpenAPI 3.1.1 validation and an explicit target/runtime surface diff for AT-002.
- `reports/acceptance_status.json` covering all 68 acceptance IDs without treating
  unexecuted specifications as passes.
- A new Git repository was initialized locally. No commit was created.

The runtime intentionally exposes only `/healthz` at P00. It does not advertise
the 23 target operations in `contracts/openapi.yaml`; `POST /v1/runs` returns 404
until its durable P01 implementation is present.
